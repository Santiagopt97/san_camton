# hotel-ui

Librería de interfaz compartida por `clientes-front`, `habitaciones-front` y `reservas-front`
(paleta del hotel + componentes reutilizables). Se importa con el alias `hotel-ui`.

Componentes: Button, Card, Alert, Badge, Spinner, Toolbar, DataTable, Pager, Modal, ConfirmModal,
Field/Input/Select/Textarea/Checkbox/FormGrid/FormActions, AppShell, RequirePerfil.
Utilidades: `createSession(loginUrl)` (token con vencimiento y perfil), `useDebouncedEffect`.
Estilos: `import 'hotel-ui/theme.css'`.
