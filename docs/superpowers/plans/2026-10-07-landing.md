# Landing page pública Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Una landing pública (`landing-front`, puerto 5177) que muestre las habitaciones reales con fotos y precios y lleve al registro o al login de la aplicación.

**Architecture:** `habitaciones-api` expone un endpoint anónimo y mínimo (`GET /api/publico/habitaciones`) que agrupa las habitaciones activas por tipo. `landing-front` es un proyecto Vite + React independiente, de una sola página con anclas, que reutiliza el tema y el `Carousel` de `hotel-ui` y lee ese endpoint sin credenciales.

**Tech Stack:** ASP.NET Core 8 + xUnit (`WebApplicationFactory`), React 18, Vite 5, Vitest + React Testing Library.

**Spec:** `docs/superpowers/specs/2026-10-07-landing-design.md`

## Global Constraints

- Rama de trabajo: `feat/landing` (sale de `develop`). No se hace `push`; lo hace el usuario.
- Commits con el correo `santirramos@gmail.com` (ya configurado) y **sin** `Co-Authored-By` ni menciones a Claude.
- Nunca imprimir ni commitear secretos (`.env`: `SUPABASE_*`, `JWT_KEY`). Las únicas ediciones permitidas a `.env` locales son líneas no secretas: `CORS_ORIGINS` en `habitaciones-api/.env` y la creación de `landing-front/.env` (Task 4); se hacen con un reemplazo puntual que no imprime el resto del archivo.
- El endpoint público devuelve **solo** `tipo`, `capacidad`, `precioDesde` e `imagenes[{ url }]`. Nunca número de habitación, piso, estado, descripción ni ids. Solo habitaciones activas.
- Una tarjeta por tipo: `capacidad` = máxima del grupo; `precioDesde` = menor `precio_noche`; lista ordenada por `precioDesde` y luego por `tipo`; máximo 6 imágenes (primero las de la habitación más barata, dentro de cada una por `orden`).
- Respuesta con `Cache-Control: public, max-age=60`. Es un GET: sin cabecera anti-CSRF ni cookie.
- La landing hace `fetch` **sin credenciales**; `VITE_API_URL` (por defecto `http://localhost:5003`) y `VITE_APP_URL` (por defecto `http://localhost:5173`) llevan valor por defecto en el código.
- Textos de interfaz en español. .NET 8: antes de usar `dotnet` en cada terminal, `export DOTNET_ROOT=/opt/homebrew/opt/dotnet@8/libexec; export PATH=/opt/homebrew/opt/dotnet@8/bin:$PATH`.
- Cada llamada de shell empieza de cero: las variables y funciones no persisten entre llamadas.
- Clases CSS propias de la landing con prefijo `ln-`. `hotel-ui` no se modifica.
- Puertos: auth-api 5001, habitaciones-api 5003; auth-front 5173, habitaciones-front 5174, **landing-front 5177**.

## Review Focus

1. El endpoint público no filtra datos internos (número, piso, estado, descripción, ids) en ninguna ruta de la respuesta. (Task 1)
2. Las habitaciones dadas de baja nunca aparecen y un tipo cuyas habitaciones están todas de baja desaparece. (Task 1)
3. Un tipo sin imágenes y una base sin habitaciones no rompen la landing: se ve «Sin foto» y «Próximamente». (Tasks 1 y 3)
4. Si la API está caída, responde error o el navegador la bloquea (CORS), la landing muestra un mensaje claro en la sección y el resto de la página sigue usable. (Task 3)
5. Los botones apuntan a la aplicación (`/login`, `/registro`) incluso sin ningún `.env`, y una cookie vencida en el navegador no impide ver la landing. (Tasks 1 y 3)

`habitaciones-api/Controllers/PublicoController.cs`:

```csharp
using HabitacionesApi.Data;
using HabitacionesApi.Models;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace HabitacionesApi.Controllers;

// Datos públicos para la landing: sin autenticación y con lo mínimo
[ApiController]
[AllowAnonymous]
[Route("api/publico/habitaciones")]
public class PublicoController(HabitacionesDbContext db) : ControllerBase
{
    public const int MaxImagenes = 6;

    [HttpGet]
    [ResponseCache(Duration = 60, Location = ResponseCacheLocation.Any)]
    public async Task<IActionResult> Listar(CancellationToken ct)
    {
        var habitaciones = await db.Habitaciones.AsNoTracking().Where(h => h.Activo)
            .Select(h => new { h.Id, h.Tipo, h.Capacidad, h.PrecioNoche, h.CreadoEn }).ToListAsync(ct);
        var ids = habitaciones.Select(h => h.Id).ToList();
        var imagenes = await db.HabitacionImagenes.AsNoTracking().Where(i => ids.Contains(i.HabitacionId))
            .OrderBy(i => i.Orden).ThenBy(i => i.CreadoEn)
            .Select(i => new { i.HabitacionId, i.Url }).ToListAsync(ct);
        var porHabitacion = imagenes.ToLookup(i => i.HabitacionId, i => new ImagenPublica(i.Url));

        var lista = habitaciones.GroupBy(h => h.Tipo).Select(grupo =>
        {
            var masBaratasPrimero = grupo.OrderBy(h => h.PrecioNoche).ThenBy(h => h.CreadoEn).ToList();
            return new HabitacionPublica(
                grupo.Key,
                grupo.Max(h => h.Capacidad),
                grupo.Min(h => h.PrecioNoche),
                masBaratasPrimero.SelectMany(h => porHabitacion[h.Id]).Take(MaxImagenes).ToList());
        }).OrderBy(x => x.PrecioDesde).ThenBy(x => x.Tipo).ToList();

        return Ok(lista);
    }
}
```

`landing-front/src/Habitaciones.jsx`:

```jsx
import { useEffect, useState } from 'react'
import { Alert, Card, Carousel, SIN_FOTO, Spinner } from 'hotel-ui'
import { listarHabitaciones } from './api.js'
import { cop } from './formato.js'

export default function Habitaciones() {
  const [estado, setEstado] = useState({ cargando: true, error: false, tipos: [] })

  useEffect(() => {
    let vivo = true
    listarHabitaciones()
      .then((tipos) => { if (vivo) setEstado({ cargando: false, error: false, tipos }) })
      .catch(() => { if (vivo) setEstado({ cargando: false, error: true, tipos: [] }) })
    return () => { vivo = false }
  }, [])

  return (
    <section id="habitaciones" className="ln-seccion" aria-labelledby="titulo-habitaciones">
      <h2 id="titulo-habitaciones">Nuestras habitaciones</h2>
      {estado.cargando && <Spinner />}
      {estado.error && <Alert>No pudimos cargar las habitaciones. Intenta de nuevo más tarde.</Alert>}
      {!estado.cargando && !estado.error && estado.tipos.length === 0 && <p className="ln-vacio">Próximamente</p>}
      <div className="ln-habitaciones">
        {estado.tipos.map((t) => (
          <Card as="article" key={t.tipo} className="ln-habitacion">
            <Carousel images={t.imagenes} alt={`Habitación ${t.tipo}`} fallback={SIN_FOTO} />
            <h3>{t.tipo}</h3>
            <p>Hasta {t.capacidad} {t.capacidad === 1 ? 'persona' : 'personas'}</p>
            <p className="ln-precio">Desde <strong>{cop(t.precioDesde)}</strong> / noche</p>
          </Card>
        ))}
      </div>
    </section>
  )
}
```
